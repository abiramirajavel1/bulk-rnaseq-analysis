# Bulk RNA-seq Analysis

## Project overview

This project demonstrates a reproducible workflow
for analysing bulk RNA sequencing data using R
and Bioconductor.

## Objectives

- Explore RNA-seq sample quality and variation.
- Perform exploratory data analysis.
- Identify differentially expressed genes.
- Visualise gene expression patterns.
- Interpret biological pathways and processes.
- Document the analysis for reproducibility.

## Tools

- R
- Bioconductor
- DESeq2
- ggplot2
- Git and GitHub

## Dataset

Dataset selection and experimental design
will be documented here.

## Workflow

1. Dataset selection and metadata inspection.
2. Exploratory data analysis.
3. Differential expression analysis.
4. Visualisation and biological interpretation.
5. Reproducibility and reporting.
